# TecnoStock - Sistema de Control de Inventario

Aplicación web desarrollada en PHP 8, MySQL (PDO), Bootstrap 5 y JavaScript para gestionar el catálogo de productos y los movimientos de entrada y salida de inventario de TecnoStock.

## Instalación local (XAMPP)
1. Copiar la carpeta `tecnostock` dentro de `C:\xampp\htdocs\`.
2. Iniciar **Apache** y **MySQL** en XAMPP.
3. Importar o ejecutar `sql/tecnostock.sql` en `http://localhost/phpmyadmin`.
4. Acceder desde el navegador a `http://localhost/tecnostock`.
